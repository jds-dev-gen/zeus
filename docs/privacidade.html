Política de privacidade do Zeus

O Zeus é um browser pessoal, usado apenas pelo seu autor.

Dados da conta Google

  • O Zeus pede acesso apenas à pasta de dados privada da própria app na Google Drive (âmbito drive.appdata) e ao endereço de email da conta, para mostrar com que conta está ligado.
  • Nessa pasta guarda os artigos guardados, coleções e destaques do utilizador, para os sincronizar entre os seus aparelhos. Não lê nem altera nenhum outro ficheiro da Drive.
  • Os dados vão diretamente dos aparelhos do utilizador para a Google. Não passam por nenhum servidor do Zeus e não são partilhados, vendidos nem usados para publicidade.
  • As credenciais de acesso ficam guardadas de forma cifrada no próprio aparelho. O acesso pode ser retirado a qualquer momento nas definições do Zeus ou em myaccount.google.com/permissions.

O uso dos dados recebidos das APIs da Google cumpre a Google API Services User Data Policy, incluindo os requisitos de uso limitado.
